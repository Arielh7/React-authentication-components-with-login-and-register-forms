## Description

Modern and responsive authentication components built with **React + Vite**. Includes **Login** and **Register** forms with advanced validation using `react-hook-form`. Perfect for quick integration into any React project.

## Features

### Login
- ✅ Basic field validation
- ✅ Email format validation
- ✅ Secure password input
- ✅ Server error handling

### Register
- ✅ **Full name** - Letters and spaces only
- ✅ **Email** - Strict format validation
- ✅ **Secure password** - Uppercase, lowercase, number, special character
- ✅ **Password confirmation** - Must match
- ✅ **Terms and conditions** - Required acceptance
- ✅ **Show/Hide** password toggle
- ✅ **Real-time password** requirements checklist
- ✅ **Visual feedback** - Error and valid states
- ✅ **Responsive design** - All devices
- ✅ **Smooth animations**
- ✅ **Server error** handling
